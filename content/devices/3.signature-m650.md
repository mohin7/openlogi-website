The Signature M650 is the one device whose capabilities have been captured from
real hardware with `logi-probe` and published in the
[OpenLogi repository](https://github.com/mohin7/openlogi/blob/master/docs/devices/signature-m650.md).
Everything below came off the wire, from a unit on a Logi Bolt receiver running
firmware `RBM16.02.B0013` (HID++ 4.5).

## Buttons

| Control | Remappable in OpenLogi |
| --- | --- |
| Left click | No — locked by the firmware |
| Right click | No — locked by the firmware |
| Middle click | Yes |
| Back | Yes |
| Forward | Yes |

Three physical buttons can be remapped to a keystroke, a media key, a mouse
button, a shell command, a URL or a workspace action. Left and right click
refuse both remapping and diversion. That is the firmware's decision, and a
sensible one: a mouse with no working left click leaves no way to undo the
change.

The mouse also reports a virtual control that streams pointer movement while
held — the hook a gesture feature would use. OpenLogi does not offer gestures
yet.

## DPI

Adjustable DPI (`0x2201`) ranges from **400 to 4000 in steps of 100**, with
1000 as the default. OpenLogi writes the value to the mouse, so it keeps it
with OpenLogi closed.

The M650 has no separate pointer-speed feature, so pointer speed and DPI are
the same setting on this mouse.

## Battery

The mouse reports its level through unified battery (`0x1004`). It runs on an
AA cell, so there is no charging state to show.

## What the hardware does not support

These are absent from the mouse's feature table, so no software on Linux — or
anywhere else — can configure them over HID++:

- **SmartWheel settings.** The M650's SmartWheel is a mechanical design; there
  is no SmartShift feature to control.
- **Horizontal scrolling** — no hardware for it.
- **Report rate** — not exposed over HID++.
- **Onboard profiles** and **onboard button remaps** — the mouse cannot store
  them, so remapped buttons need OpenLogi running and are re-applied each time
  the mouse reconnects.

## Check your own unit

Firmware revisions can differ. To compare yours with the capture above:

```bash
./target/release/logi-probe
```

The probe comes with the source build; see [Installation](/docs/installation).
For other models, see [Supported devices](/devices).
